## 写新笔记的约定

- 文件名：`<主题>-YYYY-MM-DD.md`，主题用短横线，例如 `ai-scheduling-2026-11-01.md`
- 至少写清：**假设 → 方法 → 数据 → 结论 → 没采用什么/为什么**
- 评测结论必须写清口径：`per-match` / `fixed`，局数，是否双向换槽位，A/A 是否通过
- 性能结论必须写清机器、CPU 核、是否 warmup、用的是 wall 还是 CPU 时间
- 大规模产物放 `out/`，不要提交；笔记里给出生成命令和本地路径
